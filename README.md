# Sprint 7 - Тестирование API Яндекс Самокат

Проект автотестов для API сервиса Яндекс Самокат.

## Структура проекта

### api/ - Клиенты для работы с API
- `base_api.py` - Базовый класс для API запросов
- `courier_api.py` - Методы для работы с курьерами
- `order_api.py` - Методы для работы с заказами

### data/ - Данные и конфигурация
- `endpoints.py` - Все URL эндпоинты API
- `test_data.py` - Тестовые данные

### utils/ - Вспомогательные утилиты
- `generators.py` - Генераторы тестовых данных

### tests/ - Автотесты
#### courier/ - Тесты курьеров
- `test_courier_creation.py` - Тесты создания курьера
- `test_courier_login.py` - Тесты авторизации курьера

#### order/ - Тесты заказов
- `test_order_creation.py` - Тесты создания заказа
- `test_order_list.py` - Тесты списка заказов

### conftest.py - Фикстуры pytest
- Фикстуры для API клиентов и тестовых данных
